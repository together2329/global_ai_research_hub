# 원본과 운영 기준

조직·사람의 원본은 HR이고, 온톨로지는 연구에 필요한 최소 식별자·관계·기간·근거를 연결합니다. 이름 변경과 이동이 있어도 ID를 재사용하며, 기존 소속과 연구 참여 이력을 덮어쓰지 않습니다.

| 원본 | 권위가 있는 사실 | 자동 확정할 수 없는 사실 |
| --- | --- | --- |
| HR | 조직 식별자·상하위 구조·재직·소속 기간 | 프로젝트 책임, 개별 기술 전문성 |
| 승인된 Project Registry | 프로젝트 참여, 참여 조직, 공식 역할 | 실제 Agent 사용·성능 결과 |
| 검토된 Skills Registry | 근거와 평가 기준이 있는 전문성 판단 | 모든 시점·상황의 능력 또는 인사 평가 |
| GitLab | Commit·MR·코드 작성 기록 | Project Owner·전문가 지정 |
| 실행 로그·CI·Simulation | 실제 실행, 도구 설정, 결과와 Artifact | 양산·실리콘 결과가 없는 경우 그 성과 |
| GPU Scheduler·EDA Environment | 자원 할당·Job·라이선스 사용 | 연구 성과나 인과적 생산성 개선 |
| Confluence 등 문서 | 요구사항·설계·의사결정의 명시적 기록 | 문서 밖의 미확인 기술 관계 |
| 논문·공식 벤치마크·표준·업체 자료 | 해당 자료의 내용·공개일·저자가 제시한 검증 범위 | 독립 재현, 조직의 실제 채택·호환·효과 |

SourceRecord에는 원본 위치, 종류, 권위 범위, 조회 시각을 보존합니다. 원본 시스템의 전체 HR 데이터·문서·로그를 이 저장소에 복제하는 방식으로 시작하지 않습니다. 실제 데이터 연동 시에는 원본의 허용 범위와 최신성을 확인합니다.

## 접근 범위

객체와 근거에는 `public`, `internal`, `restricted_hr` 접근 분류를 둡니다. 더 공개적인 객체에서 더 제한적인 객체를 직접 참조하면 validator가 오류를 냅니다. 실제 서비스는 조회자 권한에 따라 노드·관계·근거 링크와 파생 결과를 함께 필터링해야 합니다. 메타데이터 검사만으로 인증이나 권한 집행이 구현되는 것은 아닙니다.

Person의 기본 모델에는 이름·안정적 외부 키·재직 상태·HR 원본 참조만 두었습니다. 이메일, 전화번호, 생년월일, 급여, 인사평가 등은 이 연구 연결 목적의 기본 필드에 포함하지 않았습니다. 실제 운영에서는 내부 키를 공개 URL에 노출하지 않도록 별도 매핑을 사용합니다.

## 변경과 검토

- Research Owner는 목적·대표 분야·주요 결과와 프로젝트 역할을 확인합니다.
- Domain Steward는 기술 용어·Area 경계·별칭과 비교 조건을 검토합니다.
- Platform Owner는 ID 매핑·연동·접근 범위·품질 규칙을 운영합니다.
- AI Agent는 분류와 관계를 제안하고 근거를 찾습니다. 스스로 추론한 역할·전문성을 공식 사실로 승격하지 않습니다.

후보 관계는 검토 후 `verified` 또는 `rejected`로 바꿉니다. 정정 시 이전 근거와 정정 이유를 보존합니다. HR와 프로젝트 기록이 충돌하면 사실 종류별 원본 권위를 따라 검토하고, 현재 소속으로 과거의 연구 참여 조직을 다시 계산해 덮어쓰지 않습니다.

## 현재 구현 범위

현재 저장소에는 제안 스키마, 통제 용어, 실제 공개 문헌 Registry, 가상 내부 그래프, 로컬 validator와 예제 조회 CLI가 있습니다. 공개 문헌은 원문 링크·날짜·확인 범위와 요약만 보존하며 자료 전체를 복제하지 않습니다. HR·GitLab·Confluence·CI·자원 시스템의 실제 커넥터, 사용자 인증, 증분 동기화, 감사 로그 서비스, 그래프 DB는 아직 구현하지 않았습니다. 1,000명 규모의 실제 데이터 적재·조회 성능도 향후 검증 대상입니다.

공개 연구 추가 시 원문 내용과 공개일을 확인하고 검토 범위를 기록합니다. 발표 당시의 under_development 상태를 시간이 지났다는 이유만으로 available로 바꾸지 않습니다. 후속 공개 근거를 새 기록으로 추가해 상태 변경 이유를 보존합니다. 정기 수집 자동화와 무인 공개는 현재 모듈의 기능이 아닙니다.
